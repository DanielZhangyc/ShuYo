# 注意事项
## 签到
刷卡或人脸识别通过闸机后系统会自动签到，签到时间为预约开始时间的前后15分钟内
若未按时签到将被记录为违约行为，座位释放供他人预约

## 暂离
若使用过程中需要暂时离开座位，应执行暂离操作，座位将为您保留30分钟（用餐时间段11:00~13:00、17:00~19:00暂离时间为60分钟）
通过闸机数据进行监督，未按时返回将被记录为违约行为，座位释放供他人预约

## 退座
到预约结束时间，系统自动退座，座位释放供他人预约
未到预约结束时间需提前离开应进入预约卡片点击“退座”按钮，或使用企业微信扫描座位对应二维码点击“退座”按钮，座位释放供他人预约

# 预约规则
1. 预约开始时间为：前1天的20:00始，可预约次日8:00-22:00座位使用
2. 单次预约时长：不超过8小时
3. 座位预留时长：15分钟
4. 暂离时长：30分钟（用餐时间段11:00~13:00、17:00~19:00暂离时间为60分钟）

# 违规规则
1. 预约后没有在规定时间内签到，将被记录为违约
2. 暂离未在规定时间内返回，将被记录为违约
3. 离开不退座或未暂离，将被记录为违约
4. 违约次数达到3次，将暂停自第3次违约记录起算的7日内预约功能

# 约法三章
1. 使用座位前请先以本人身份进行预约，在预约时段内，预约人拥有该座位使用权。没有预约的同学应将座位让给已预约同学，杜绝“霸座”行为
2. 禁止使用任何非正常手段进行签到等操作，否则暂停预约功能
3. 您所有履约情况将被记录，请履约守信，点滴积累自己的信用记录
